# Kai project knowledge

Use the repository's established documentation home, or this default
package-owned root, for project knowledge from the first edit on a branch.
Each package owns its vocabulary and paths. Keep one canonical document;
proposed and accepted revisions do not move between private and public folders.

Repository review and named-authority requirements still govern acceptance.
Private coordination, agent memory, evidence, and restricted working material
stay in `.kai/`. Committing is not external-publication permission.
