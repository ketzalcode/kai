# area-plugins — backlog

Initiative-scoped deferred proposals — the `proposal_channel` named in
`northstar.md`. An expansion discovered inside `area-plugins` lands here, not in
`kai/coordination/backlog.md`, which is for unaffiliated proposals. This file is
the **one-way valve** `kai-core-scope-discipline`'s deferrals flow into; only the
steward opens it outward, by promoting an entry to an authoritative
`kai/coordination/items/*.md` record when it fits `scope.current`.

**Five proposals booked; four fully parked, one half-promoted.** All five were
generated by steward amendments A19–A21 and by the `principal-swe-infra`
tool-allowlist diagnosis, and were held in coordination threads until this file
could exist. **P5(a) was promoted on 2026-08-28-0125** into
`area-plugins-tool-allowlist-fix`; P5(b) and P1–P4 remain parked with their
triggers unmet.

Parked by `principal-product-manager` (steward) at the `scope-acceptance` of
`area-plugins-taxonomy-round-2` (amendment A19, 2026-08-27-2138). Survives the
2153 nine-plugin override **unchanged** — a plugin that is now smaller still
needs its job named.

```

                    product already had. It is a COPY defect, not a packaging

                    generate-catalog.mjs:40-42 files both routers under
                    "Direction — The two front doors. Everything else is
                    reachable through them", rendered at
                    docs/reference/agents-and-skills.md:32-34 and checked by
                    docs:check.

                    "Direction" / "Workspace foundation" blurbs so the front
                    door and the operating system read as one coherent job.
                    Product owns the copy per A4; principal-technical-writer
                    executes.
  friction_cost:    One array literal plus `npm run docs:generate`, byte-checked
                    and fully reversible.
  mission_tradeoff: scripts/generate-catalog.mjs is NOT an area-plugins target,
                    so this sits outside the initiative's blast radius — which
                    is precisely the argument for using this axis rather than
                    minting identity to fix prose. Deferring costs nothing;

                    still moving under the nine-plugin split.
  scope_target:     milestone 3, surface-rename.
  owner:            principal-product-manager -> principal-technical-writer.
```

**Promotion trigger:** `area-plugins-taxonomy-round-3` reaches `completed`, so
