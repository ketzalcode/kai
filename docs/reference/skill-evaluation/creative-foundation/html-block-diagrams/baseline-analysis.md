## Budget ruling and case

This phase contains five no-target-guide controls only. The frozen current
guide is retained as a reference/audit input and was not loaded by any control
actor. No current-guide actor arm was run.

The fixed case requested exactly one self-contained HTML structural diagram
from supplied containment, ownership-lane, component, and label facts. It
supplied no status chips, lifecycle state, artifact paths, implementation
claims, brands, or brand tokens.

Manual reading checked:

1. useful representation of the outer boundary and two ownership lanes;
2. exact grounding in the supplied components, labels, descriptions, and
   containment;
3. a complete standalone HTML document with inline CSS and no external
   dependencies or scripts;
4. no invented status, artifact-path, brand, technology, or relationship
   metadata;
5. responsive layout treatment for a narrower viewport.

## Control result

All five controls met all five observable points.

Each returned one complete HTML document with:

- one `Search service` outer boundary;
- separate `Request lane` and `Index lane` regions;
- the four supplied components under their correct lane;
- only the supplied component descriptions;
- embedded responsive CSS and no external resources or JavaScript.

No control invented status chips, artifact paths, lifecycle state, technology
choices, brand identity, or cross-lane relationships.

## Interpretation

This establishes a strong no-guide control baseline, not an efficacy result.
The final matched comparison is reserved for five controls versus five future
candidate samples on this exact frozen case. No diagram candidate was authored
or run here.

## Limits

- Ambient harness and core instructions remained a confound.
- Outputs were read as source artifacts with explicit filename/hash mapping.
- No browser, HTML renderer, viewport screenshot, accessibility tree, or visual
  inspection was used.
- Self-containment and grounding were assessed from source, not rendered
  behavior.
