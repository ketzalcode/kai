PROPOSAL
  problem:          Operators need to compare similar search results without opening many tabs.
  proposed_change:  Add a persistent comparison tray that lets users pin up to three results and compare them side by side on the Search Results page.
  friction_cost:    Adds a new pinned-results surface, pin/unpin controls in each row, tray state management, and a new comparison interaction.
  mission_tradeoff:  It improves review efficiency, but it also introduces a new page-level capability and extra UI/state complexity beyond the current filter/sort/save/open flow.
  scope_target:     Search Results page comparison enhancement; treat as a separate proposal, not folded into the current screen work.
