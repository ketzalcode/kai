This expands scope, so it should be treated as an unadopted proposal rather than folded into the current Search Results page work.

PROPOSAL
  problem:          Operators need an easier way to compare several similar search results without opening multiple tabs and losing context.
  proposed_change:  Add a persistent comparison tray that lets operators pin up to three results from the list and compare them side by side on the page.
  friction_cost:    Adds a new pinned-results surface, pin/unpin controls in each row, tray state management, and a new side-by-side comparison interaction.
  mission_tradeoff: The idea improves comparison efficiency, but it clearly adds a new step and surface, so it should not be absorbed into current screen work without explicit approval.
  scope_target:     Search Results page comparison workflow / a later compare-mode milestone if one is approved.
