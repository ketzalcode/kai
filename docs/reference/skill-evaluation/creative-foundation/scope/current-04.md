PROPOSAL
  problem: Search Results page has no way to compare similar results without opening multiple tabs.
  proposed_change: Add a persistent comparison tray that lets operators pin up to three results and compare them side by side on the page.
  friction_cost: Adds a new pinned-results surface, pin/unpin controls in each row, tray state management, and a new side-by-side comparison interaction.
  mission_tradeoff: It would make comparison faster and reduce tab switching, but it introduces a new step and surface, so it expands the current screen rather than folding into it.
  scope_target: Future Search Results comparison mode or a dedicated follow-on milestone.
