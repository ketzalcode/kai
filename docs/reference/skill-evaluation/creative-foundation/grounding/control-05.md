Recommended direction: move active filter chips to a dedicated second row beneath the main toolbar controls at 1280px.

Why: the current width audit shows six chips on the main row push Save search offscreen, while the supplied surface pattern already uses a second row when filters need more room. Hidden chips would be worse than a taller toolbar here, and there is no approved overflow pattern to rely on.

ASCII sketch:
[ Search field.................................. ][ Sort ][ Save search ]
[ Chip 1 ][ Chip 2 ][ Chip 3 ][ Chip 4 ][ Chip 5 ][ Chip 6 ]

Follow-up before adoption: none required for this decision. If you want an overflow treatment later, that should be proposed separately as a new pattern rather than assumed here.
