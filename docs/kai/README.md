# Kai project knowledge

This is the default package-owned home for Git-suitable project knowledge,
authored here from the first edit on a branch. Proposed and accepted revisions
keep the same path; repository review and named-authority requirements
determine acceptance, not the directory or a private-to-public move.
On the default branch, documents state accepted direction unless their reviewed
content explicitly labels a proposal as Proposed. Obtain required named
acceptance before merging accepted content.

Direction is operator-owned. Private coordination, memory, evidence, restricted
working material, and runtime history remain in the private workspace. Never
commit them as part of a knowledge bundle. External publication remains a
separately authorized action.

The repository's current architecture and development decisions live in the
active documentation set under `docs/`; Git history is the archive for
superseded decisions and release records.
